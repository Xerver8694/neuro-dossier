> A client-side cognitive reframing engine that translates non-linear processing, sensory thresholds, and executive patterns into tactical operating profiles.

---

## Overview

Traditional psychological frameworks and corporate performance rubrics treat neurodivergence through a deficit lens. **Neuro-Dossier** treats divergent cognitive wiring as an alternative system architecture. 

By submitting unstructured qualitative inputs (lived experiences, sensory triggers, dopamine friction, hyperfocus behaviors), the engine parses and maps the data into a structured, tactical operational profile:

* **Assigned System Codename & Archetype:** Categorizes baseline cognitive processing style.
* **Core Operational Mechanic:** Defines the high-level pattern recognition or execution method.
* **Super-Traits & Strategic Advantages:** Identifies high-yield problem-solving and focus dynamics.
* **System Vulnerabilities & Throttles:** Outlines concrete points of cognitive failure, overstimulation, or friction.
* **Ideal Operating Architecture:** Translates needs into actionable self-advocacy boundaries and environmental accommodations.

---

## Key Features

* **Zero Tracking / Zero Persistence:** Runs entirely client-side. No database, no accounts, and no data logging. API keys are utilized strictly in-memory during active sessions.
* **Export-Ready Self-Advocacy Profiles:** Renders clean, structured cards that can be printed or screenshotted directly for workplace accommodation discussions or personal operating manuals.
* **Custom LLM Routing via OpenRouter:** Configured to interface directly with OpenRouter endpoints, allowing users to leverage high-reasoning models on their own credentials.
* **Lightweight Footprint:** Built with zero frameworks, zero external build tools, and pure semantic HTML/CSS/JS.

---

## Tech Stack

* **Frontend:** Semantic HTML5, CSS Grid/Flexbox
* **Logic:** Vanilla JavaScript (ES6+)
* **Engine Integration:** OpenRouter API (`fetch` streaming/JSON payload architecture)
